01 / WHAT THIS IS

先把这一页说清楚

它不是新闻，
也不是官方发布。

这一页是什么

  • 同学们自己写的、自己拍的、自己做的东西，原文刊登
  • 署名是投稿人自己选的昵称，发布前经过本人同意
  • 每一条都能看到是谁投的、什么时候投的、用什么授权
  • 想改或者想撤，随时可以提出来，撤下来的稿子会从页面上移除

这一页不是什么

  • 不是学校官方发布，不代表大连东软信息学院的立场
  • 不是「奶龙要闻」——那边的故事是虚构的，这边的人是真实的
  • 不是文学比赛，没有门槛，写清楚一件小事就够了
  • 不放真实姓名、学号、手机号和宿舍门牌，这些一律不收

投稿页面里出现的个人观点只属于投稿人本人。凡是能核实的事实性内容，引用时请回到原始来源；本站不代替任何官方渠道答疑。

第一次把 Hello World 打印出来的时候

投稿人：一只夜猫子 · 奶龙软件工程学院

开学第二周，我终于把开发环境装好了。书上说，第一件事是打印一行 Hello World。我照着敲完，运行，屏幕上跳出来一长串红色的字。当时我盯着那串字看了很久，心想：我是不是不适合学这个。

第二个晚上，隔壁床的同学凑过来看了一眼，说你这个分号是中文的。我换成英文分号，再运行一次，屏幕上出现了一行绿色的小字。那一瞬间我确实笑了出来，笑自己为一个分号折腾了两个晚上。

后来我们又一起改了好几处小问题。我发现难的不是那个分号，是不知道可以去问谁。所以想把这件小事写下来：如果你也在第一步卡住，先别急着怀疑自己，找个同学一起看一眼，也许就过去了。

标签：新手 · Debug · 同学 · 授权：CC BY-NC-SA 4.0

2026.09.28 · 作品分享 示例

花一周写了个「哪间教室还亮着灯」的小网页

投稿人：写不完就不写 · 人工智龙学院

起因很简单：晚自习想找个安静教室，我得从一楼走到四楼，一间一间看。走了三趟之后我决定写个东西，把这十分钟省下来。

第一版丑得离谱，只有一个列表，数据还是我手动填的。后来室友说，你加个按楼层筛选吧。加完他又说，能不能标出来哪间人最少。就这么被他推着改了三版，功能没变多，但确实越来越好用。

这件事让我第一次体会到：一个东西好不好用，不是自己说了算，得看别人用的时候会不会卡住。我们后来把这个小工具丢给同层的同学用，收到了十几条反馈，其中一半是我没想到的。

标签：小工具 · 一次迭代 · 宿舍项目 · 授权：CC BY-NC-SA 4.0

2026.09.20 · 影像记录 示例

秋天最好看的那段楼梯，我拍了三年

投稿人：抱着相机上课 · 数字摸鱼艺术学院

大二那年秋天随手拍了一段楼梯，因为阳光刚好落在台阶上。后来每年秋天我都会回到同一个位置，站在同一级台阶上，拍一张同样的照片。

三年下来，树长大了，栏杆重新刷过漆，我的相册里多了两张几乎一样的图。把它们并排放的时候，才发现变化其实很小，但确实是变了。

我把这三张图做成了对比图。做的时候没想太多，只是觉得这种「看起来没变但其实变了」的感觉挺有意思的。

03 / HOW TO SUBMIT

怎么投稿

投一次就够了，
不用先写得很好。

STEP 01

在仓库提一个 Issue

打开本站的 GitHub 仓库，选「同学投稿」模板，把想说的话写进去。不会用 Git 也没关系，按模板填就行。

写不完整也没事，漏掉的部分维护者会来问。

STEP 02

或者直接提一个 PR

在 content/submissions/ 下新建一个 JSON 文件，照着已有文件的字段填：标题、昵称、日期、正文、授权。图片放进 assets/ 并在 JSON 里引用。

一条投稿一个文件，改起来清楚，也方便回退。

STEP 03

合并后重新构建发布

维护者在本地跑 node tools/build-submissions.mjs，把投稿渲染成静态页面并提交。合并进 main 之后，线上大约一分钟就会更新。

站点本身没有任何后端，投稿不经过服务器，全靠重新构建发布。

04 / BEFORE YOU SEND IT

投稿须知

几件先说好的事，
免得后面麻烦。

四条约定
写你自己的事，用你自己的话。

一、必须是原创。文字、照片、代码都请自己写、自己拍、自己做。引用别人的内容要写明出处，不要整段搬过来。

二、同意公开展示。提交即表示同意本站以你选的昵称署名发布，并采用你指定的授权方式（默认 CC BY-NC-SA 4.0）。

三、不写别人的隐私。真实姓名、学号、手机号、宿舍门牌、未公开的群聊记录一律不要出现在投稿里；写到同学时请用昵称或模糊说法。

四、随时可以撤回。投稿发布后如果改变主意，在仓库里说一声，维护者会把这一条从页面上移除并重新发布。

当前页面上标着「示例」的条目，是为了把界面演示清楚而放的占位内容，不是真实投稿；收到第一条真实投稿后就会被替换掉。投稿里如果有事实性错误，欢迎在 GitHub 仓库指出，我们改完会重新发布。

05 / SOURCES & CREDITS

来源与引用

这一页的内容从哪来，
以及怎么署名。

内容从哪来

  • 正文、图片与标签均由投稿人提供，发布前经过本人同意
  • 稿件的原始记录保存在仓库的 content/submissions/ 目录，一条一个文件
  • 本页的正文由 tools/build-submissions.mjs 从这些文件生成，不手工改写
  • 想核对某一条投稿的原文，可以在仓库历史里找到对应的提交

引用与授权

  • 每一条投稿都标注了授权方式，默认 CC BY-NC-SA 4.0；投稿人可以指定别的许可
  • 转载时请署名投稿人的昵称，并保留原文链接与授权说明
  • 投稿中的图片由投稿人提供，除非另有说明，不随正文本站二次授权
  • 本页不搬用学校校徽、学校 Logo 与各组织的素材
